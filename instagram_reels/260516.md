## 로컬 릴스 렌더 예시 (`make_reel.py`)

저장소 루트에서:

```bash
python scripts/make_reel.py create \
  --script-file instagram_reels/260516_heygen.txt \
  --scene-dir "data/260516_순천서면" \
  --tts-voice ko-KR-InJoonNeural \
  --music "assets/music/8.Sunlit Daydream.wav" \
  --music-volume 0.03 \
  --font "/usr/share/fonts/truetype/nanum/NanumGothicBold.ttf" \
  --output output/reels/260516_final_bgm.mp4
```

나레이션 화면 자막까지 넣을 때는 `--subtitle` 추가.
